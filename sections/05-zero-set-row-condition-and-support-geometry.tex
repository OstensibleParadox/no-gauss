\section{Zero-Set Row Condition and Support Geometry}
\label{sec:zero-set-row-condition-and-support-geometry}

Positivity in the main theorem removes a separate null-set obstruction from
the finite-marginal likelihood ratios.  When the density has zeros,
Hilbert--Schmidt proximity remains the metric accumulation condition, but
equivalence also requires the zero-set row condition for the operator and its
inverse.  We first prove this exact replacement, then show how bounded and
one-sided supports can reduce the equivalence group to permutation classes.
The hypotheses are stated separately for each result;
\eqref{eq:main-assumptions} is not a standing assumption.
